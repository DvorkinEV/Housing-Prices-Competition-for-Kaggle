# Прогнозирование цен на жильё: ансамблевые модели и стекинг

**Результат в соревновании:** 196‑е место из 5 372 команд (топ 3.6 %).  
**Задача:** спрогнозировать стоимость продажи домов на основе структурированных данных.

## О проекте

Это ML‑проект для соревнования по прогнозированию цен на жильё. Основная цель — продемонстрировать эффективность **стекинга** (stacking) как метода ансамблевого обучения.

Ключевые особенности:
- Использование трёх базовых моделей: RandomForest, XGBoost, LightGBM.
- Стекинг с кросс‑валидацией (5 фолдов) и мета‑моделью Ridge.
- Тщательная предобработка данных (заполнение пропусков, кодирование, масштабирование).
- Логарифмирование целевой переменной для стабилизации обучения.

## Как работает стекинг

Стекинг — это метод ансамблевого обучения, где:
1. **Базовые модели** (RandomForest, XGBoost, LightGBM) обучаются на тренировочных данных.
2. Их предсказания на валидационных фолдах (OOF, *out‑of‑fold*) становятся **входными признаками** для мета‑модели.
3. **Мета‑модель** (Ridge) обучается на этих предсказаниях и делает финальный прогноз.

Преимущества:
- Снижение переобучения за счёт кросс‑валидации.
- Объединение сильных сторон разных алгоритмов.
- Повышение точности по сравнению с отдельными моделями.

## Используемые модели

1. **RandomForest**  
   - `n_estimators=200`, `max_depth=12`.
2. **XGBoost**  
   - `n_estimators=3000`, `learning_rate=0.01`, `max_depth=6`.
3. **LightGBM**  
   - `n_estimators=3000`, `learning_rate=0.01`, `num_leaves=31`.
4. **Стекинг (Ridge как мета‑модель)**  
   - Вход: OOF‑предсказания трёх базовых моделей.
   - Мета‑модель: `Ridge(alpha=1.0)` с масштабированными входными данными.
